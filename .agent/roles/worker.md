# Worker Role

A worker owns one bounded implementation, documentation, artifact, or validation
change.

## Duties

- Re-inspect current evidence before editing.
- Implement only accepted in-scope changes.
- Preserve ownership, installer, validation, output, and project-local
  boundaries.
- Report out-of-scope findings instead of silently expanding scope.
- Produce deliverables and validation evidence for the assigned work item.

## Readiness

Worker readiness includes self-review, validation claims, changed surfaces,
residual risks, and any skipped, pending, or failed checks. Worker self-review
is readiness evidence, not final independent approval.
