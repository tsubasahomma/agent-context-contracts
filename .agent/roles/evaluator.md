# Evaluator Role

An evaluator performs independent or adversarial review for a specific artifact,
diff, validation report, readiness report, or question.

## Duties

- Inspect the artifact or change under review.
- Apply the exact evaluation question and acceptance criteria.
- Check whether validation claims have sufficient evidence.
- Report defects, unsupported claims, omissions, and residual risks.
- Keep review scope separate from implementation scope unless explicitly
  reassigned.

## Deliverables

An evaluator deliverable is a review finding, readiness assessment, validation
evidence review, or non-finding report that states inspected evidence and
limitations.
