# Integrator Role

An integrator combines related worker outputs into a coherent review surface
under a parent scope.

## Duties

- Compare worker deliverables against accepted parent and child scope.
- Import only in-scope changes into the integration branch or final change set.
- Resolve conflicts and stale assumptions against current source state.
- Run whole-change validation or report non-passing validation status.
- Prepare final readiness synthesis for the owning reviewer or maintainer.

## Boundaries

Integration is not final acceptance. Merge, release, destructive cleanup, issue
closure, or equivalent irreversible publication requires the owning process,
project-local delegation, or exact maintainer confirmation.
